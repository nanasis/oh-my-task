# Oh My Task

Installation and usage documentation: **https://the-jiahaojiang.github.io/oh-my-task/**

## Pi

```bash
pi install git:github.com/The-JiahaoJiang/oh-my-task
```

Restart Pi after the first installation. After an update, use `/reload` or restart Pi.

## Other coding agents

Install to the shared Agent Skills directory with one command:

```bash
npx --yes github:The-JiahaoJiang/oh-my-task
```

If your agent documents a different skill directory:

```bash
npx --yes github:The-JiahaoJiang/oh-my-task --path /path/to/skills/oh-my-task
```
